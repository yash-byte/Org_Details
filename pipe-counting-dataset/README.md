# Straight Pipe Counting Dataset

50 yard images of **straight pipes only** (no L-shaped / elbow fittings).

| Field | Description |
|-------|-------------|
| Filename | `pipes-count-{NN}-{view}.jpg` |
| Count | Target pipe count = `NN` (1–50). Count each pipe **once**. |
| Views | `side`, `top`, `front`, `iso`, `angled` |
| Highlight | Neon green square on circular pipe openings |

See `manifest.csv` for the full index.
