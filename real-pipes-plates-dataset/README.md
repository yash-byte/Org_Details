# Real Pipes & Plates Dataset

200 photoreal industrial images. **No grass / green lawn backgrounds.**

| Folder | Count | Content |
|--------|-------|---------|
| `pipes/` | 100 | Straight steel/metal pipes (counts 1–100) |
| `plates/` | 100 | Flat steel plates (counts 1–100) |

**Views:** side, top, front, iso, angled  
**Backgrounds:** concrete, asphalt, gravel, warehouse floors  
**Labels:** see `manifest.csv` (count each item once)
