# Layered L-Show Steel Pipes (Test Dataset)

100 studio images for testing layered pipe counting / pick detection.

## Spec
- **Background:** pure white
- **Pipe:** steel / L-show straight pipes
- **Highlight:** neon green **square** on each circular opening
- **Max layers:** 4
- **Layer pattern (full):** ground **15** → **14** → **13** → top **12**
- **Variants:** `full` (complete) and `picked` (upper-layer pipes removed)

## Naming
`lp-{001..100}-{full|picked}-{front|side|iso|angled}.jpg`

See `manifest.csv`.
